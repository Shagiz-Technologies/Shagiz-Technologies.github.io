Application bugs

For reproducible TeleVault problems, search existing reports and then open a sanitized bug report with app version, Android version, device model, install source, steps, expected behavior, and safe logs.

Feature requests

Explain the user problem, not only a proposed implementation. Changes involving architecture, permissions, encryption, login, sync, restore, storage format, or dependencies require maintainer agreement before implementation.
