TeleVault privacy controls

Data & Deletion

Local TeleVault data and remote Telegram backups are stored in different places and must be removed separately.

On this pageAccountsLocal dataTelegram dataVaultInquiries
Important: Logging out, clearing app data, or uninstalling TeleVault does not automatically delete channels, messages, media, or metadata snapshots stored in Telegram.

1. TeleVault and Telegram accounts

TeleVault authenticates an existing Telegram account. It does not create a separate Shagiz-operated cloud account. Telegram controls phone-number changes, login codes, account recovery, restrictions, and Telegram account deletion.

2. Remove local TeleVault data

Local data can include the Drift/SQLite database, settings, bucket references, labels, queue state, diagnostics, thumbnails, temporary files, TDLib sessions, metadata-backup state, and Vault-related records.

  1. Verify any upload you intend to keep directly in Telegram.
  2. Use TeleVault's logout flow. It cancels scheduled background work, stops active synchronization, closes the local Telegram session, and removes local account data, TDLib storage, temporary files, and account secrets.
  3. When prompted, choose whether encrypted local Vault objects and installed recovery material should be retained or removed.
  4. For a complete local reset, open Android Settings, select TeleVault under Apps, and clear app storage, or uninstall TeleVault.

Android menu wording varies by manufacturer. Clearing app storage or uninstalling normally removes application-private local data.

3. Remove Telegram buckets, messages, and media

Remote content remains in the user's Telegram account until the user removes it. To delete remote backup data:

  1. Open the relevant bucket channel in Telegram.
  2. Delete individual backup messages, or delete/leave the channel as appropriate.
  3. Review the TeleVault metadata channel and delete encrypted metadata snapshots no longer needed.
  4. Confirm deletion in Telegram. Telegram's own deletion and retention behavior applies.

Shagiz Technologies does not operate the user's Telegram account and cannot directly delete its channels, messages, media, or snapshots. For Telegram account access or account deletion, use Telegram Support and Telegram's own account controls.

4. Vault objects and Recovery Key

Vault objects are encrypted by TeleVault before their Vault upload path. Deleting the local app database does not necessarily delete encrypted Vault objects stored in Telegram. Delete the corresponding Telegram messages or bucket channel when remote removal is required.

Deleting or losing the Vault Recovery Key can make remaining encrypted Vault objects permanently unrecoverable. Confirm that no needed Vault backup remains before destroying the final Recovery Key copy.

5. Metadata snapshots and Safe Uninstall

Encrypted metadata v5 snapshots may be stored in Telegram. Safe Uninstall can create and verify a recent metadata snapshot before local removal, but it does not erase Telegram content and does not guarantee that every file or device-local path can be restored.

Delete every exported metadata copy from Telegram, downloads, email, external storage, or other destinations selected by the user when complete removal is desired.

6. Privacy or deletion-process inquiries

Non-sensitive questions may be submitted through TeleVault GitHub Issues.

Do not include phone numbers, Telegram usernames or IDs, login codes, credentials, private media, databases, metadata snapshots, session files, Recovery Keys, or unredacted logs. GitHub Issues cannot authenticate ownership of a Telegram account and Shagiz Technologies cannot delete Telegram-hosted data on a user's behalf.
