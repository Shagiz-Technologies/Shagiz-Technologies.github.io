TeleVault privacy controls

Data & Deletion

Local app data and Telegram-hosted backups are stored in different places and must be handled separately.

On this pageAccountsLocal dataTelegram dataMetadata packagesInquiries
Important: Uninstalling TeleVault does not delete bucket channels, messages, files, or metadata packages stored in Telegram.

1. TeleVault and Telegram accounts

TeleVault authenticates an existing Telegram account. It does not create a separate Shagiz-operated TeleVault server account in the current implementation. Account recovery, phone-number changes, restrictions, and Telegram account deletion are controlled by Telegram.

2. Local TeleVault data

Local app data can include the Drift/SQLite metadata database, settings, labels, bucket references, upload states, diagnostics, thumbnails or temporary files, vault-related records, metadata-backup state, and TDLib session data.

  1. Pause backup work and verify any upload you intend to keep.
  2. Use supported TeleVault logout, deletion, or safe-uninstall controls where appropriate.
  3. To remove all local application data on Android, open Android Settings, find TeleVault under Apps, choose Storage, and clear app data. Menu wording varies by device.
  4. Uninstall TeleVault to normally remove its application-private local data.

Logging out terminates the local Telegram session. The current implementation must not be assumed to erase every local metadata record merely because logout completed. Clear application data when a complete local reset is required.

3. Telegram buckets, messages, and files

Telegram-hosted data remains until it is deleted through Telegram or a supported TeleVault control. To remove it:

  1. Open the relevant bucket channel in Telegram.
  2. Delete individual backup messages or delete/leave the channel as appropriate.
  3. Review any dedicated TeleVault metadata channel and remove metadata backup messages you no longer need.
  4. Confirm deletion in Telegram. Telegram's own retention and deletion behavior applies.

Shagiz Technologies does not operate the authenticated Telegram account and cannot directly delete channels, messages, or files held there. If account access is lost, contact Telegram Support.

4. Metadata backup packages

Encrypted metadata packages may exist in Telegram, email, downloads, cloud drives, external storage, or any destination selected through sharing. Delete each copy from its storage destination and from trash or recovery folders if complete removal is desired.

Deleting a local TeleVault database does not automatically delete exported packages. Deleting an exported package does not delete Telegram media backups.

5. Before safe uninstall

Safe Uninstall is an optional preparation flow intended to capture recent metadata before removal. It is not required for Android uninstall, does not guarantee restoration, and does not erase Telegram content. Keep the recovery passphrase separate and verify the backup result before uninstalling.

6. Privacy or deletion inquiries

Deployment blocker: The approved private contact for deletion inquiries is not yet configured: PRIVACY_CONTACT_EMAIL_REQUIRED.

Until it is configured, a non-sensitive process question may be opened through GitHub Issues. Do not include a phone number, Telegram username or ID, media, metadata package, database, login code, credentials, or private logs. GitHub Issues cannot be used to authenticate ownership of a Telegram account.
